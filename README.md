SE11, choose View, enter ZWRVWAALAPRCTP, click Change.
Go to the tab View Fields (Sichtfelder). You should see the existing fields of the table listed there, probably SERVICE_TYPE, PROCESS_TYPE and BMS_MOVEMENT_TYPE.
Click the button Table fields (Tabellenfelder) at the bottom, select ZWRTWAALAPRCTP, tick BMS_QTY_INFO in the list and copy it over. It appears as a new row with view field BMS_QTY_INFO, table ZWRTWAALAPRCTP, field BMS_QTY_INFO.
On the tab Maintenance Status (Pflegestatus), check that Access is still "read, change, delete and insert" and that Display/Maintenance Allowed is set. Don't change anything there.
Save, Check, Activate.
